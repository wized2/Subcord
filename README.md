# Subcord

Personal / experimental Discord client helper: mobile Discord Web + on-device message translation.

**Not a product.** Built for personal use. Anyone may fork or try it under MIT — no support, no roadmap, no store listing.

## What it does

- Opens Discord in a mobile WebView (login cookies stay on device)
- Injects a small script that translates non-English messages under the originals
- Remembers the last channel URL

## Install

[Releases](https://github.com/wized2/Subcord/releases) — use at your own risk.

## Build

```bash
./gradlew assembleRelease
```
